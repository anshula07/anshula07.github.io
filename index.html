Documentation Principles

Audience First

Documentation should be written for the person using it, with terminology, depth, and structure appropriate to their knowledge and goal.

Task Focused

Procedures should help users complete tasks efficiently, with prerequisites, steps, expected results, and verification where appropriate.

Consistent

Consistent terminology, headings, UI references, formatting, and information structure make documentation easier to use.

Maintainable

Documentation should be structured so that it can be reviewed, versioned, updated, and maintained as products evolve.
