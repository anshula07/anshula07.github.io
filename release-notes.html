RELEASE NOTES

Sentinel Privilege Manager 2.4.0

Feature and Enhancement Release

This release introduces improved privilege request workflows, policy management enhancements, expanded reporting capabilities, and fixes for issues affecting administration and endpoint operations.

Product Sentinel Privilege Manager
Version 2.4.0
Release Date 17 September 2026
Release Type Feature Release

1. Release Overview

SPM 2.4.0 focuses on improving administrative workflows, increasing visibility into privilege activity, and simplifying policy management.

3 New Features
4 Enhancements
5 Bug Fixes

2. Release Highlights

Area What's New
Privilege Requests Administrators can configure multi-level approval workflows.
Policy Management Policy search and filtering have been expanded for faster administration.
Reporting Privilege activity reports now include additional filtering options.
Endpoint Operations Agent synchronization handling has been improved for intermittent connectivity.

3. New Features

Multi-Level Privilege Approval

Feature

Administrators can now configure approval workflows with multiple approval stages for elevated privilege requests.

Capability Description
Approval Stages Configure sequential approval steps for sensitive access requests.
Approver Assignment Assign different approvers to individual workflow stages.
Status Tracking View the current approval stage and request status.

Scheduled Privilege Access

Feature

Users can now request privilege access for a predefined future time window.

This allows administrators to support planned maintenance activities without granting persistent elevated access.

Privilege Activity Dashboard

Feature

A new dashboard provides a consolidated view of privilege requests, approvals, active elevated sessions, and recently completed requests.

4. Enhancements

Area Enhancement User Impact
Policy Management Added filtering by policy status, assignment group, and last modified date. Administrators can locate policies faster.
Application Search Improved application search with partial name matching. Reduces the time required to locate applications.
Reports Added date-range and user filters to privilege activity reports. Provides more focused reporting results.
Agent Synchronization Improved retry handling when communication with the management server is temporarily unavailable. Helps endpoints recover synchronization without manual intervention.

5. Bug Fixes

Component Issue Resolution
Policy Management Policy status was not refreshed immediately after an update. Status refresh handling has been corrected.
Privilege Requests Request details could become unavailable after a rejected request was reopened. Request state handling has been updated.
Reporting Exported reports could omit records when a date filter was applied. Report filtering and export processing have been corrected.
Agent Agent status could remain stale after temporary network interruptions. Endpoint status synchronization has been improved.
Administration Validation messages were not displayed consistently for incomplete policy forms. Form validation messaging has been standardized.

6. Upgrade Notes

Review the following items before upgrading an existing SPM environment.

  • Review the release changes with the SPM administrator.
  • Back up the existing SPM configuration according to your organization's backup procedure.
  • Review existing privilege approval workflows.
  • Validate application and endpoint policies after the upgrade.
  • Test privilege request and approval workflows before enabling them for all users.
  • Review updated reporting and dashboard functionality.
Important: Upgrade procedures and prerequisites may vary by deployment architecture. Refer to the applicable installation and upgrade documentation before performing an upgrade.

7. Known Limitations

The following limitations apply to this sample release.

Area Limitation Workaround
Scheduled Access Scheduled privileges cannot currently be created for recurring time windows. Create individual access windows as required.
Dashboard Activity data may take a short period to appear after a new event. Refresh the dashboard after the activity has been processed.
