How to Request Temporary Application Privileges

A guided product walkthrough for Sentinel Privilege Manager (SPM), demonstrating how an end user requests, submits, and tracks temporary application access.

Video walkthrough: Approximately 1 minute 45 seconds. The walkthrough demonstrates a fictional end-user privilege request workflow.

Overview

This product-training sample demonstrates how an end user can request temporary elevated access to an application through Sentinel Privilege Manager.

The walkthrough uses a fictional business scenario in which a user requires temporary access to Acme Database Studio for a specific task. The request is submitted with a business justification and remains subject to approval.

What You'll Learn

01. Access the SPM Console

Sign in using assigned credentials and navigate to the SPM dashboard.

02. Create a Request

Open Privilege Requests and start a new application access request.

03. Configure Temporary Access

Select the application, choose temporary privilege access, and specify the required duration.

04. Submit and Track

Provide a clear business justification, submit the request, and review its approval status.

Step-by-Step Workflow

1

Sign in to SPM

Sign in to the Sentinel Privilege Manager console using your assigned credentials.

2

Open Privilege Requests

From the dashboard navigation, open Privilege Requests to view existing requests or create a new request.

3

Start a New Request

Select New Request to begin requesting elevated application access.

4

Select the Application

Choose the application for which elevated access is required. The example uses Acme Database Studio.

5

Configure Temporary Access

Select Temporary Privilege and specify how long the elevated access is required. The example uses two hours.

6

Provide Business Justification

Enter a clear explanation of why elevated access is required. Specific justification helps approvers understand the business need.

7

Review and Submit

Review the application, access type, duration, and justification before selecting Submit.

8

Track Approval

After submission, SPM displays the request status. Once approved, temporary elevated access becomes available according to the configured policy.

Documentation principle: Temporary access should be requested only for the duration and level of privilege required to complete the task. This supports controlled and auditable access.
